<feature>
  <name>Workspace prefix parsing utility</name>
  <files>src/task/workspace-prefix.util.ts, src/task/workspace-prefix.util.spec.ts</files>
  <behavior>
    Pure function: parseWorkspacePrefix(input: string) -> { title: string, workspaceOverride: 'work' | 'personal' | null }

    Cases:
    - "@work Buy office supplies" -> { title: "Buy office supplies", workspaceOverride: "work" }
    - "@personal Call dentist" -> { title: "Call dentist", workspaceOverride: "personal" }
    - "@WORK Fix printer" -> { title: "Fix printer", workspaceOverride: "work" } (case insensitive)
    - "@Personal Plan vacation" -> { title: "Plan vacation", workspaceOverride: "personal" } (case insensitive)
    - "Buy groceries" -> { title: "Buy groceries", workspaceOverride: null } (no prefix)
    - "  @work  Trim spaces  " -> { title: "Trim spaces", workspaceOverride: "work" } (trimmed)
    - "@workspace Not a valid prefix" -> { title: "@workspace Not a valid prefix", workspaceOverride: null } (only @work and @personal)
    - "" -> { title: "", workspaceOverride: null } (empty string)
  </behavior>
  <implementation>
    Regex match on `^@(work|personal)\s+` (case insensitive). If match, extract workspace override and strip prefix from title. Trim both input and result.
  </implementation>
</feature>

<feature>
  <name>Parent status derivation utility</name>
  <files>src/task/task-status.util.ts, src/task/task-status.util.spec.ts</files>
  <behavior>
    Pure function: deriveParentStatus(childStatuses: TaskStatus[]) -> TaskStatus

    Per CONTEXT.md locked derivation rule:
    - 0% done = active, 1-99% = in_progress, 100% = done
    - Blocked/deferred only if ALL children are blocked/deferred

    Cases:
    - [] (no children) -> TaskStatus.active (standalone task fallback)
    - [done] -> TaskStatus.done (single child done = 100%)
    - [done, done, done] -> TaskStatus.done (all done = 100%)
    - [active, active] -> TaskStatus.active (0% done)
    - [captured, active] -> TaskStatus.active (0% done, captured counts as not done)
    - [done, active] -> TaskStatus.in_progress (50% done = 1-99%)
    - [done, in_progress] -> TaskStatus.in_progress (some done, some in progress)
    - [done, captured] -> TaskStatus.in_progress (1 done out of 2)
    - [blocked, blocked] -> TaskStatus.blocked (all blocked)
    - [deferred, deferred] -> TaskStatus.deferred (all deferred)
    - [blocked, deferred] -> TaskStatus.blocked (all blocked/deferred mix -> blocked)
    - [blocked, active] -> TaskStatus.active (not all blocked/deferred, 0% done)
    - [done, blocked] -> TaskStatus.in_progress (some done, but not all blocked/deferred since done is present)
    - [in_progress] -> TaskStatus.active (0% done, in_progress child does not count as done)
  </behavior>
  <implementation>
    Count done children vs total. Apply rules in order: (1) 100% done -> done, (2) all blocked/deferred -> check if all deferred then deferred else blocked, (3) some done -> in_progress, (4) default -> active.
  </implementation>
</feature>

  <name>TaskService domain operations</name>
  <files>

    src/task/dto/update-task.dto.ts
    src/task/task.service.ts
    src/task/task.service.spec.ts

  <behavior>
    TaskService injectable with PrismaService dependency.

    **CreateTaskDto fields:**
    - title: string (required, min length 1)
    - workspaceId: string (required -- resolved by caller, not by prefix parsing within DTO)
    - description?: string (optional)
    - sourceInput?: string (optional -- original brain dump text)
    - status?: TaskStatus (optional, defaults to captured)
    - priority?: TaskPriority (optional, defaults to medium)
    - deadline?: Date (optional)
    - parentId?: string (optional -- for sub-task creation)
    - position?: number (optional, defaults to 0)

    **UpdateTaskDto fields:** All of CreateTaskDto fields optional except workspaceId (cannot change workspace). Plus:
    - blockedReason?: string (optional)
    - deferredUntil?: Date (optional)

    **Service methods:**

    create(dto: CreateTaskDto):
    - Parse workspace prefix from title using parseWorkspacePrefix()
    - If prefix detected and workspaceOverride is not null, resolve the workspace ID for the override name (query workspace by name), use that instead of dto.workspaceId. Use the cleaned title.
    - If parentId provided, verify parent exists and parent.parentId is null (depth enforcement). Throw BadRequestException if parent already has a parent.
    - Create task with Prisma, return created task with children included
    - If status is 'done', set completedAt to now

    findAll(workspaceId: string):
    - Return top-level tasks (parentId is null) in workspace
    - Filter: deletedAt is null
    - Include children (where deletedAt is null, ordered by position asc)
    - Order by createdAt desc
    - For each parent task that has children, compute derived status using deriveParentStatus() and attach to response

    findOne(id: string, workspaceId: string):
    - Return single task by id in workspace
    - Filter: deletedAt is null
    - Include children (where deletedAt is null, ordered by position asc)
    - If task has children, compute derived status
    - Throw NotFoundException if not found

    update(id: string, workspaceId: string, dto: UpdateTaskDto):
    - Find task first (must exist, must be in workspace, must not be soft-deleted)
    - If task has a parentId (is a sub-task) and dto changes parentId, verify new parent exists and new parent.parentId is null
    - If dto.parentId is explicitly set to null, promote sub-task to standalone task
    - If status changing to 'done', set completedAt to now. If changing FROM 'done', clear completedAt
    - Update with Prisma, return updated task with children

    softDelete(id: string, workspaceId: string):
    - Set deletedAt to now
    - Also soft-delete all children (cascade soft delete)
    - Return the soft-deleted task

    restore(id: string, workspaceId: string):
    - Set deletedAt to null
    - Also restore all children
    - Return the restored task

    **All methods enforce workspace isolation:** Every Prisma query includes `workspaceId` in the where clause. No method exists without a workspaceId parameter.

    **Test cases for TaskService (mock PrismaService):**
    - create: creates task with correct workspace, default status captured
    - create: parses @work prefix and resolves workspace
    - create: creates sub-task when parentId provided
    - create: rejects sub-task of sub-task (depth enforcement)
    - create: sets completedAt when status is done
    - findAll: returns only tasks in specified workspace with deletedAt null
    - findAll: includes children ordered by position
    - findAll: computes derived parent status
    - findOne: returns task by id and workspace
    - findOne: throws NotFoundException when not found
    - update: updates task fields
    - update: validates new parentId for reparenting
    - update: sets completedAt when transitioning to done
    - update: clears completedAt when transitioning from done
    - softDelete: sets deletedAt on task and children
    - restore: clears deletedAt on task and children
  </behavior>
  <implementation>
    Follow NestJS service patterns. Use constructor injection for PrismaService. Use class-validator decorators on DTOs (IsString, IsOptional, IsEnum, MinLength, IsUUID, IsDate). TaskModule provides TaskService and imports WorkspaceModule (to resolve workspace names for prefix parsing). Wire TaskModule into app.module.ts imports.

    For derived parent status: after fetching a parent task with children, call deriveParentStatus(children.map(c => c.status)) and attach the result. The parent's own status column in the database is effectively overridden by the derived value when children exist. Store the derived status in a `derivedStatus` property on the return value (or override the `status` field -- prefer adding a `derivedStatus` field to keep the stored status visible).
  </implementation>
</feature>
