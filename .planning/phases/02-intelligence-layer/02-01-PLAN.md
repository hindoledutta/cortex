    2. Create `src/llm/llm.types.ts`:
       - Define `LlmOperation` type: `'decomposition' | 'classification' | 'follow-up' | 'enrichment'`
       - Define `MODEL_MAP` constant: decomposition -> 'claude-opus-4-6', all others -> 'claude-sonnet-4-6' (per user locked decision)
       - Define `LlmResponse` interface: `{ content: string; usage: { input_tokens: number; output_tokens: number } }`
       - Define `DecompositionResultSchema` using Zod:
         ```typescript
         z.object({
           needs_decomposition: z.boolean(),
           parent_task: z.object({
             title: z.string(),
             description: z.string().nullable(),
             priority: z.enum(['high', 'medium', 'low']),
             deadline: z.string().nullable(),
           }).nullable(),
           sub_tasks: z.array(z.object({
             title: z.string(),
             description: z.string().nullable(),
             priority: z.enum(['high', 'medium', 'low']),
             position: z.number(),
           })),
           follow_up_needed: z.boolean(),
           detected_gaps: z.array(z.string()),
         })
         ```
       - Export `DecompositionResult` type via `z.infer<typeof DecompositionResultSchema>`
       - Define `FollowUpResultSchema` using Zod:
         ```typescript
         z.object({
           questions: z.array(z.object({
             text: z.string(),
             target_task_ids: z.array(z.string()),
             gap_type: z.enum(['deadline', 'priority', 'context', 'scope']),
           })),
         })
         ```
       - Export `FollowUpResult` type
       - Define `EnrichmentResultSchema` using Zod:
         ```typescript
         z.object({
           task_updates: z.array(z.object({
             task_id: z.string(),
             field: z.string(),
             value: z.string(),
           })),
           new_sub_tasks: z.array(z.object({
             title: z.string(),
             description: z.string().nullable(),
             priority: z.enum(['high', 'medium', 'low']),
           })),
           summary: z.string(),
         })
         ```
       - Export `EnrichmentResult` type
       - Define `ClassificationResultSchema` using Zod:
         ```typescript
         z.object({
           intent: z.enum(['new_brain_dump', 'follow_up_answer', 'command', 'unclear']),
           is_continuation: z.boolean(),
           confidence: z.number(),
         })
         ```
       - Export `ClassificationResult` type

    3. Create `src/llm/llm.service.ts`:
       - Injectable NestJS service
       - Constructor: instantiate `new Anthropic()` client (reads ANTHROPIC_API_KEY from env automatically per SDK convention)
       - `createMessage(operation: LlmOperation, systemPrompt: string | Array<{type: 'text', text: string, cache_control?: {type: 'ephemeral'}}>, messages: Anthropic.MessageParam[], outputSchema?: Record<string, unknown>, maxTokens?: number): Promise<LlmResponse>`
         - Select model from MODEL_MAP based on operation
         - Build MessageCreateParams with model, max_tokens (default 4096), system prompt, messages
         - If outputSchema provided, add `output_config: { format: { type: 'json_schema', schema: outputSchema } }`
         - Call `this.client.messages.create(params)`
         - Log via NestJS Logger: `LLM [${operation}] model=${model} input=${response.usage.input_tokens} output=${response.usage.output_tokens}`
         - If cache tokens available, also log: `cache_read=${response.usage.cache_read_input_tokens ?? 0}`
         - Extract text content from response.content (find block with type 'text')
         - Return `{ content: textBlock.text, usage: { input_tokens, output_tokens } }`
       - Use `@nestjs/common` Logger (same pattern as PrismaService and other Phase 1 services)
