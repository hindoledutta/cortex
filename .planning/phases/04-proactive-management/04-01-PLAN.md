   - `async update(data: { reminderLeadMinutes?: number; checkInAfterDays?: number; notificationHourUtc?: number })`: Upsert the settings row with provided fields. Use `prisma.settings.upsert({ where: { id: 'default' }, create: { ...defaults, ...data }, update: data })`.

3. Create `src/scheduler/scheduler.service.ts`:
   - Injectable service implementing `OnModuleInit` and `OnModuleDestroy`
   - Constructor: inject `ConfigService`, create pg-boss instance:
     ```typescript
     this.boss = new PgBoss({
       connectionString: this.config.getOrThrow<string>('DATABASE_URL'),
       max: 2,  // Minimal pool for Neon free tier
       retentionDays: 7,
       archiveCompletedAfterSeconds: 3600,
     });
     ```
   - `onModuleInit()`: Register error handler (`this.boss.on('error', ...)`), call `await this.boss.start()`, call `await this.boss.createQueue('deadline-reminder')`. Log "pg-boss started".
   - `onModuleDestroy()`: Call `await this.boss.stop({ graceful: true })`. Log "pg-boss stopped".
   - Expose `boss` as a readonly property so ReminderService (Plan 02) can call `boss.send()` and `boss.work()`.
   - Use Logger from `@nestjs/common`.

4. Create `src/scheduler/notification.service.ts`:
   - Injectable service with dependencies:
     - `@InjectBot() private readonly bot: Telegraf<Context>` (from nestjs-telegraf)
     - `ConfigService` for `OWNER_CHAT_ID`
     - `MessageFormatterService` (optional -- for reusing escapeHtml if exposed, otherwise inline a private escapeHtml method)
   - Store `ownerChatId` as `number` from `config.getOrThrow<string>('OWNER_CHAT_ID')` parsed with `parseInt()`.
   - **IMPORTANT**: For `@InjectBot()` to work, the module importing NotificationService must also import TelegrafModule or the module that provides it. The SchedulerModule will need to import TelegramModule for this.

   Three public methods:

   a. `async sendDeadlineReminder(task: { id: string; title: string; deadline: Date })`:
      - Build HTML text: `<b>⏰ Deadline Reminder</b>\n\nTask: <b>{escaped title}</b>\nDeadline: {formatted date}`
      - Inline keyboard: Done, Start, Defer buttons using `formatCallbackData(CALLBACK_PREFIX.TASK, action, task.id)` from telegram.constants
      - Send via `this.bot.telegram.sendMessage(this.ownerChatId, text, { parse_mode: 'HTML', ...keyboard })`

   b. `async sendCheckInPrompt(task: { id: string; title: string; updatedAt: Date })`:
      - Calculate days since update: `Math.floor((Date.now() - task.updatedAt.getTime()) / 86400000)`
      - Build HTML text: `<b>📋 Check-in</b>\n\nHow's <b>{escaped title}</b> going?\nIt's been {N} days since the last update.`
      - Inline keyboard: Done, Still working (callback `task:start:{id}`), Blocked (callback `task:defer:{id}`)
      - Send via bot.telegram.sendMessage

   c. `async sendDeferredResurface(task: { id: string; title: string })`:
      - Build HTML text: `<b>🔄 Task Resurfaced</b>\n\n<b>{escaped title}</b> was deferred and is now ready for your attention.`
      - Inline keyboard: Start, Done, Defer buttons
      - Send via bot.telegram.sendMessage

   Private helper: `escapeHtml(text: string)` -- escape `<`, `>`, `&` for HTML parse_mode. Import from MessageFormatterService if it exports it, or re-implement (3 lines).

If `@InjectBot()` fails with "Nest could not find Telegraf instance", add `TelegrafModule` import using `TelegrafModule.forRootAsync(...)` -- BUT this would duplicate config. Instead, the simplest fix is to add `TelegrafModule` to TelegramModule's exports. **Add TelegrafModule to TelegramModule's exports array** if not already there.
   - Providers: SchedulerService, NotificationService
   - Exports: SchedulerService, NotificationService (consumed by Plan 02's ReminderService and PollingService)
