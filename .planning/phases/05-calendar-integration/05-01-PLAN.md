**5. Create OAuth setup script** (`scripts/google-oauth-setup.ts`):

A standalone script that:
1. Reads GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET from `.env` (or process.env)
2. Creates an OAuth2Client
3. Generates an authorization URL with `access_type: 'offline'`, `prompt: 'consent'`, scope `https://www.googleapis.com/auth/calendar.events`
4. Prints the URL for the user to visit in their browser
5. Prompts the user to paste the authorization code (reads from stdin)
6. Exchanges the code for tokens
7. Prints the refresh_token for the user to add to `.env` as GOOGLE_REFRESH_TOKEN
8. Uses `http://localhost:3333` as redirect URI (starts a tiny local HTTP server to capture the callback, or uses `urn:ietf:wg:oauth:2.0:oob` copy/paste flow -- prefer the copy/paste approach for simplicity)

Use `google-auth-library` OAuth2Client for all auth operations. Use `readline` from Node.js for stdin input. Use `dotenv` to load `.env`. Import format: `import { OAuth2Client } from 'google-auth-library';`

**Important:** Do NOT use `@googleapis/calendar` in this script -- only `google-auth-library` is needed for the setup flow.

**1. Create GoogleAuthService** (`src/calendar/services/google-auth.service.ts`):

```typescript
@Injectable()
export class GoogleAuthService implements OnModuleInit {
  private oauth2Client: OAuth2Client;

  constructor(private readonly config: ConfigService) {}

  onModuleInit() {
    this.oauth2Client = new OAuth2Client(
      this.config.get<string>('GOOGLE_CLIENT_ID'),
      this.config.get<string>('GOOGLE_CLIENT_SECRET'),
    );
    this.oauth2Client.setCredentials({
      refresh_token: this.config.get<string>('GOOGLE_REFRESH_TOKEN'),
    });
  }

  getClient(): OAuth2Client {
    return this.oauth2Client;
  }
}
```

Import `OAuth2Client` from `google-auth-library`. Import `Injectable, OnModuleInit` from `@nestjs/common`. Import `ConfigService` from `@nestjs/config`.

The OAuth2Client automatically refreshes access tokens when they expire -- do NOT implement manual refresh logic.

**2. Create CalendarService** (`src/calendar/services/calendar.service.ts`):

Inject `GoogleAuthService` and `PrismaService`. Initialize `calendar_v3.Calendar` in `onModuleInit()`.

Note on type cast: The `calendar_v3.Calendar` constructor expects `auth` typed as `auth.OAuth2Client` from `@googleapis/calendar`, but `google-auth-library`'s `OAuth2Client` is the same class at runtime. Use `as unknown as auth.OAuth2Client` cast per research finding.

Methods:
- `async createEvent(params: CreateEventParams): Promise<calendar_v3.Schema$Event>` -- Calls `calendar.events.insert()` with mapped event resource. Maps: params.summary -> event.summary, params.description -> event.description, params.startTime/endTime -> event.start/end with params.timezone, params.attendeeEmails -> event.attendees[].email. Sets `sendUpdates: 'all'` if attendees present, `'none'` otherwise. After successful insert, creates a `calendarEvent` record in Prisma with taskId, googleEventId (result.data.id), calendarId, title, startsAt, endsAt, attendeeEmails. Returns result.data.
- `async queryFreeBusy(params: FreeBusyParams): Promise<BusySlot[]>` -- Calls `calendar.freebusy.query()` with params.calendarId, startDate, endDate, timezone. Extracts busy slots from `result.data.calendars?.[params.calendarId]?.busy ?? []`. Maps each to `{ start: new Date(slot.start!), end: new Date(slot.end!) }`. Returns the array.

Import types: `CreateEventParams, FreeBusyParams, BusySlot` from `../calendar.types`. Import `calendar_v3, auth` from `@googleapis/calendar`.

**3. Create ContactService** (`src/calendar/services/contact.service.ts`):

Inject `PrismaService`.

Methods:
- `async resolveNames(names: string[], workspaceId?: string): Promise<ContactResolutionResult>` -- For each name, do a case-insensitive lookup: `prisma.contact.findFirst({ where: { name: { contains: name, mode: 'insensitive' }, ...(workspaceId ? { workspaceId } : {}) } })`. Partition into resolved (with email) and unresolved arrays. Return `{ resolved, unresolved }`.
- `async create(name: string, email: string, workspaceId?: string): Promise<Contact>` -- Creates a new contact record. Uses `prisma.contact.create({ data: { name, email, workspaceId: workspaceId ?? null } })`.
- `async findAll(workspaceId?: string): Promise<Contact[]>` -- Lists contacts, optionally filtered by workspaceId.
- `async findByNameExact(name: string, workspaceId?: string): Promise<Contact | null>` -- Exact case-insensitive match for deduplication before creating.

Import `ContactResolutionResult` from `../calendar.types`.

All services use NestJS `Logger` for logging (consistent with existing patterns). All public methods are async and return Promises.
