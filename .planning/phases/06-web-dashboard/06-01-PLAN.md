Add REST API endpoints to the NestJS backend so the React dashboard can fetch tasks and workspaces over HTTP.

Output: TaskController (GET/PATCH), WorkspaceController (GET), ApiKeyGuard, CORS configuration, and a new `findAllAcrossWorkspaces()` method on TaskService.
</objective>

1. **Create `src/task/task.controller.ts`:**
   - `@Controller('api/tasks')` with `@UseGuards(ApiKeyGuard)` at the class level
   - Inject `TaskService` via constructor
   - `@Get()` endpoint: accepts optional `@Query('workspaceId') workspaceId?: string`
     - If `workspaceId` provided: call `this.taskService.findAll(workspaceId)`
     - If not: call `this.taskService.findAllAcrossWorkspaces()`
   - `@Get(':id')` endpoint: accepts `@Param('id') id: string` and `@Query('workspaceId') workspaceId: string`
     - Call `this.taskService.findOne(id, workspaceId)`
   - `@Patch(':id')` endpoint: accepts `@Param('id') id: string`, `@Query('workspaceId') workspaceId: string`, `@Body() dto: UpdateTaskDto`
     - Call `this.taskService.update(id, workspaceId, dto)`
   - Import `ApiKeyGuard` from `../guards/api-key.guard`

2. **Create `src/workspace/workspace.controller.ts`:**
   - `@Controller('api/workspaces')` with `@UseGuards(ApiKeyGuard)` at the class level
   - Inject `WorkspaceService` via constructor
   - `@Get()` endpoint: call `this.workspaceService.findAll()`
   - Import `ApiKeyGuard` from `../guards/api-key.guard`

3. **Update `src/task/task.module.ts`:**
